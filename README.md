# Amanah Finance Syariah

## Aplikasi Keuangan Digital Berbasis Prinsip Syariah Islam

Amanah Finance Syariah adalah aplikasi berbasis website yang dirancang untuk membantu pengguna mengelola keuangan secara lebih mudah, praktis, dan sesuai dengan prinsip syariah Islam.

Aplikasi ini dikembangkan dengan tampilan modern, sederhana, dan responsif sehingga dapat digunakan melalui smartphone maupun komputer.

🌐 Akses Aplikasi

Pengguna dapat mengakses aplikasi melalui tautan berikut:

Live Website: https://pixel-perfect-replay-37756.lovable.app

GitHub Repository: https://github.com/ziajahh12/Amanah_FinanceSyariah

✨ Fitur Aplikasi

Beberapa fitur yang dikembangkan dalam Amanah Finance Syariah:

- 💰 Pengelolaan keuangan.
- 📊 Pencatatan dan pemantauan transaksi.
- 🕌 Informasi dan perhitungan zakat maal.
- 📈 Rekapitulasi keuangan.
- 🔐 Sistem autentikasi pengguna.
- 🗄️ Integrasi database menggunakan Supabase.
- 📱 Tampilan responsif untuk smartphone dan komputer.

Ketersediaan fitur mengikuti versi aplikasi yang sedang berjalan.
